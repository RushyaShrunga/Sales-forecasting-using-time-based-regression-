Department Monthly Sales Forecasting Project

Run steps:
1. Open terminal inside this folder.
2. Run: python -m pip install -r requirements.txt
3. Run: python app.py
4. Open: http://127.0.0.1:5001

CSV format:
date,department,sales
2023-01-01,Electronics,42800
2023-01-01,Furniture,31650

This version is monthly-only. It does not include weekly sales forecasting.
